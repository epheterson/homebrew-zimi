# Security

This tap only points Homebrew at the releases of [Zimi](https://github.com/epheterson/Zimi): one cask, with the checksum of each release DMG. A report about the cask belongs here; a report about Zimi itself belongs in that repository's [advisory form](https://github.com/epheterson/Zimi/security/advisories/new).

## Reporting a vulnerability

Report it privately through GitHub: **[Security > Report a vulnerability](https://github.com/epheterson/homebrew-zimi/security/advisories/new)**. Please do not open a public issue, discussion or pull request for it.

Include what you found, how to reproduce it, and what an attacker could reach with it. You will get an answer as soon as I can, and credit in the advisory unless you would rather not.

## Supported versions

The latest cask, which the release workflow in Zimi rewrites on every release.
